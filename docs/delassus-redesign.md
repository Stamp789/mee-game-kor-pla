# มีเกมก็แปล — Play it in Thai

อัปเดต 23 ตุลาคม 2026 · พรีวิวในเครื่อง

## ทิศทางใหม่

อ้างอิง https://delassus.com/en/products/citrus จากการดูหน้าเว็บจริง: ใช้สีเต็มจอ วัตถุที่มีมิติ แบ่งเรื่องเป็นฉาก และวางเมนูให้น้อยชิ้น แล้วนำวิธีนำเสนอมาปรับให้เหมาะกับคลังม็อดภาษาไทย โดยใช้ภาพเกมของโปรเจกต์เอง

แนวคิดคือ **เกมเดิมที่คุณรัก ความรู้สึกใหม่ที่เข้าใจ** เปลี่ยนจากโลกมืดและประตู 3D เป็นสตูดิโอเกมสีสด กล่องเกมลอยตัว ตราภาษาไทย และการเลือกเรื่องราวที่อยากเล่น

- สีหลัก: ส้ม `#FF923C`, น้ำเงิน `#263BD7`, ครีม `#FFF8E9`
- สีรอง: ชมพู `#F7B8CB`, เหลือง `#F5D95D` และสีฉากเฉพาะเกม
- ตัวอักษร: IBM Plex Sans Thai + Space Grotesk
- รูปทรง: กล่องเกมมีสันและความหนา วงกลม ตราประทับ ปุ่มทรงแคปซูล
- การเคลื่อนไหว: หน้าเปิดมี parallax และกล่องหมุนตามการเลื่อน ช่วงเกมแนะนำตรึงฉากเต็มจอชั่วคราว แล้วหมุนกล่องและเปลี่ยนทั้ง 4 เกมตามความคืบหน้าการเลื่อน ใช้การเลื่อนปกติของเบราว์เซอร์และเลื่อนย้อนกลับได้

## โครงสร้างประสบการณ์

1. หน้าแรก — คำชวนหลัก กล่องเกมภาษาไทย และปุ่มไปคลังม็อด
2. เกมแนะนำ — 4 เกม / 4 สีฉาก มีชื่อเกม ประเภท คำแนะนำ สถานะ เวอร์ชัน และลิงก์รายละเอียด
3. เรื่องของเรา — เล่าเหตุผลในการแปล และลิงก์ไปเพจผู้แปล
4. ชวนเปิดคลัง — แสดงจำนวนเกมจากข้อมูลจริง พร้อมทางลัดตามประเภท
5. เริ่มเล่น — เลือกเกม ตรวจความเข้ากันได้ ดาวน์โหลด และติดตั้ง
6. สนับสนุน — เปิด QR ใน dialog พร้อมข้อความตรวจชื่อบัญชี
7. คลังม็อด `/mods/` — ค้นหา กรองแนวเกม / แหล่งดาวน์โหลด เรียงลำดับ บันทึกเกม เปลี่ยนกริด / รายการ และแบ่งหน้า
8. รายละเอียด `/mods/<id>/` — รุ่นเกม เวอร์ชัน วิธีติดตั้ง บันทึกอัปเดต ลิงก์ต้นทาง และแหล่งซื้อเกม

## ระบบที่ใช้ในพรีวิวนี้

ใช้ Astro สร้าง HTML ล่วงหน้า โดยข้อมูลม็อด 32 เกมยังมีแหล่งหลักเดียวที่ `src/content/mods/*.json` ไม่คัดลอกข้อมูลไปฝังในดีไซน์ใหม่

| ส่วน | ตำแหน่ง | หน้าที่ |
| --- | --- | --- |
| โครงร่วม | `src/layouts/BaseLayout.astro` | metadata, fonts, navigation, footer, search |
| หน้าแรก | `src/pages/index.astro` | เล่าเรื่องและจัดเกมแนะนำจาก content collection |
| กล่องเกม | `src/components/GameObject.astro` | วัตถุ CSS 3D ที่ใช้ซ้ำได้จากข้อมูลเกม |
| รูปแบบร่วม | `src/styles/global.css` | foundation, buttons, cards, dialogs |
| ทิศทางใหม่ | `src/styles/playful.css` | palette, shell, objects, sections และ responsive |
| ปฏิสัมพันธ์ | `src/scripts/playful.ts` | เชื่อม scroll กับตำแหน่งกล่อง สีฉาก การเลือกเกม และหยุด motion |
| ฉากตามการเลื่อน | `src/styles/scroll-journey.css` | sticky stage, กล่องครบ 6 ด้าน, parallax และรูปแบบสำหรับมือถือ / แนวนอน |
| คลังม็อด | `src/scripts/catalog.ts` | การค้นหา ตัวกรอง pagination และ URL state |
| ข้อมูลร่วม | `src/lib/mods.ts`, `src/lib/catalog.ts` | แปลง URL รูปภาพ เวอร์ชัน วันที่ และประเภท |

หน้าแรกใหม่ไม่โหลดฉาก Three.js / GSAP เดิม ใช้ CSS transforms เพื่อให้ดูมีมิติโดยไม่ต้องสร้าง WebGL context รองรับ `prefers-reduced-motion` และมีปุ่มหยุดภาพเคลื่อนไหว องค์ประกอบเลือกเกมใช้ ARIA tabs พร้อม Arrow Left / Right, Home / End และ native dialogs รองรับ Escape

หน้าเก่าบน root (`index.html`, `app.js`, `styles.css`) และไฟล์ฉากเก่ายังเก็บไว้เพื่อย้อนเทียบ งานนี้เปลี่ยนเส้นทางแอป Astro ที่ใช้พรีวิว ไม่ได้ push, deploy หรือเปลี่ยน workflow production

สำรองซอร์สก่อนเริ่มที่ `artifacts/before-delassus-20261023/src/`

## แผนเปลี่ยนระบบก่อนขึ้นเว็บจริง

- **ช่วงที่ 1 — พรีวิวดีไซน์:** หน้าแรกใหม่ พร้อมทิศทางร่วมสำหรับคลังม็อดและรายละเอียด ทดลอง flow จากเลือกเกมไปหน้าดาวน์โหลด (ทำแล้ว)
- **ช่วงที่ 2 — ข้อมูลและงานดูแล:** ตรวจวันที่ สถานะ เวอร์ชัน และแหล่งดาวน์โหลดกับผู้แปล แยกสถานะกำลังแปล / ออกแล้วเมื่อมีข้อมูลยืนยัน เพิ่มช่องทางอัปเดตข้อมูลตามวิธีทำงานจริง
- **ช่วงที่ 3 — ย้าย production:** ปรับ GitHub Actions ให้ build Astro และ deploy `dist/`, ทดสอบ base path ของโดเมนจริง, redirect ลิงก์เก่า, OG images, sitemap, favicon และหน้าหาย โดยยังไม่ทำในพรีวิวนี้
- **ช่วงที่ 4 — ตรวจรับและเปิดใช้:** ตรวจลิงก์ดาวน์โหลดภายนอกกับผู้แปล ตรวจมือถือจริง คีย์บอร์ด screen reader และความเร็ว จากนั้นเผยแพร่เวอร์ชันที่เลือก

ยังไม่เพิ่มบัญชีผู้ใช้ ฐานข้อมูล หรือ CMS เนื่องจากการค้นหาและรายการโปรดในเครื่องรองรับการใช้งานปัจจุบันได้อยู่แล้ว หากต้องซิงก์รายการโปรดข้ามอุปกรณ์หรือมีผู้แก้ข้อมูลหลายคน จึงค่อยกำหนดระบบสมาชิกและสิทธิ์แก้ไขให้ตรงงาน


เปิด http://127.0.0.1:4321/ — เซิร์ฟเวอร์ preview อ่านจาก `dist/` จึงต้อง build ใหม่หลังแก้โค้ด หรือใช้ `npm run dev` เพื่อแก้แล้วเห็นผลทันที

ตรวจความถูกต้องด้วย `npm run check` และ `npm run build` โดย build ตรวจ JSON, IDs, assets และ URL แบบ HTTPS ก่อนสร้างหน้าจริง

- `npm run check`: 0 errors / 0 warnings
- `npm run build`: ข้อมูล 32 รายการผ่านการตรวจ สร้างหน้าได้ครบ 35 หน้า
- ตรวจ responsive ผ่าน iframe ที่ความกว้าง 320, 390, 768, 1440 และ 1920 CSS px: หน้าแรกไม่มี horizontal overflow หลังแก้ตราวงกลมที่จอ 320px
- คลังม็อดและหน้ารายละเอียดตรวจที่ 390px: ไม่มี horizontal overflow
- ทดลองเปลี่ยนเกมด้วยการคลิกและปุ่มลูกศร: ชื่อ เนื้อหา สีฉาก selected tab และตัวนับเปลี่ยนตรงกัน
- ทดลองค้นหา `berseria` ทั้งช่องค้นหากลางและในคลัง: พบ Tales of Berseria 1 เกมและเปิดรายละเอียดได้
- ทดลองบันทึก / ยกเลิกบันทึกและเปลี่ยนกริด / รายการ: สถานะและ URL ทำงาน โดยคืนรายการโปรดเดิมหลังทดสอบ
- ทดลองหยุด motion และเปิด / ปิด dialog สนับสนุนด้วย Escape
- ตรวจภาพหน้าแรก ฉากเกม เรื่องของเรา คอลเลกชัน หน้ารายละเอียด และ dialog ในเบราว์เซอร์

การตรวจ responsive นี้เป็นการจำลองความกว้างในเบราว์เซอร์ ยังไม่ได้ตรวจด้วยโทรศัพท์จริงหรือยืนยันลิงก์ดาวน์โหลดภายนอกใหม่ทุกเกม ภาพพรีวิวอยู่ที่ `artifacts/delassus-preview/`

## อัปเดต: ฉากที่เคลื่อนตามการเลื่อน

- หน้าเปิด: กล่องสองใบหมุนคนละทิศ เลื่อนระดับต่างกัน และวงโคจรหมุนตามระยะเลื่อน
- เกมแนะนำ: ใช้พื้นที่เลื่อน 500svh บนคอม / 440svh บนมือถือ โดยตรึงฉาก 100svh ไว้ขณะเลื่อน ไม่ดัก wheel หรือ touch และไม่เปลี่ยนความเร็วการเลื่อนของเอกสาร

- การเปลี่ยนโลก: หมุนกล่องพร้อมเลื่อนระดับ ผสมสีพื้นหลังและสีตกแต่ง เปลี่ยนเกมและตัวเลขบทตาม scroll progress พร้อมทำให้มีเพียงข้อความของเกมปัจจุบันที่แสดงในช่วงเปลี่ยน
- ปุ่มเลือกเกมและ Arrow Left / Right, Home / End จะเลื่อนไปยังตำแหน่งเกมนั้นใน timeline เดียวกัน

- ใช้ `requestAnimationFrame` เฉพาะเมื่อเลื่อน / ปรับหน้าต่าง / ค่าภาพกำลังตามตำแหน่งเลื่อน แล้วหยุดเมื่อภาพตามทัน
