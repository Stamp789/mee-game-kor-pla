# V2 — พรีวิวหน้าแรกและหน้ารายเกม

> **23 ต.ค. 2026: พรีวิวล่าสุดเป็น Full-screen World Journey ทั้งเว็บ** — ใช้ฉากที่เลือกเป็นหน้าแรก พร้อมคลังและรายละเอียด 32 เกมในธีมฟ้า ม่วง และทอง เน้นประสบการณ์ PC/Mac อ่าน [สถานะล่าสุด](world-journey-site.md) ข้อความด้านล่างบันทึกการพัฒนารุ่นแรกไว้เป็นประวัติ

งานรอบแรกตามแผน Playable Worlds: หน้าแรกพร้อมฉาก Three.js, หน้ารายเกมจากข้อมูลเดิม และคลังสำหรับทดลองเส้นทางใช้งานจริง ทำงานใน branch `codex/redesign-v2` และพรีวิวในเครื่องก่อนนำขึ้นเว็บจริง

## เปิดพรีวิว

ใช้ Node.js ที่รองรับตาม `package.json` ของ Astro ที่ติดตั้งไว้ แล้วรันจาก root โปรเจกต์:

```powershell
npm.cmd ci
npm.cmd run assets
npm.cmd run check
npm.cmd run build
npm.cmd run preview
```

- หน้าแรก: http://127.0.0.1:4321/
- หน้ารายเกมตัวอย่าง: http://127.0.0.1:4321/mods/absolum/
- คลังม็อด: http://127.0.0.1:4321/mods/
- ใช้ `npm.cmd run dev` เมื่อต้องการแก้โค้ดพร้อม hot reload

## สิ่งที่ทำแล้ว

- Astro static routes และ TypeScript; ข้อมูลรายเกมใน `src/content/mods/`
- ย้ายม็อดทั้ง 32 รายการและสร้างหน้ารายเกมจาก template เดียวกัน
- ตรวจข้อมูลที่ย้ายทุก field กับต้นฉบับใน `app.js` ด้วย `node scripts/validate-migration.mjs` ส่วน build ปกติตรวจ ID, asset และ HTTPS ของ URL หลัก เพื่อให้ข้อมูล V2 แก้ไขต่อได้อย่างอิสระ
- หน้าแรกขาวอมเทา/น้ำเงิน มีโชว์เคสแบบสลับขนาด อัปเดต คู่มือ และช่องทางสนับสนุน
- ฉาก WebGL มีกรอบปกเกมสามมิติ วงแหวน วัตถุตัวอักษรไทย/อังกฤษ แสงและวัสดุสะท้อน ตอบสนอง pointer และตำแหน่ง scroll
- โหลด Three.js/GSAP แยกจาก JavaScript หลัก หยุด animation เมื่อนอกจอ แท็บถูกซ่อน หรือกดพัก และปล่อย resource เมื่อออกจากหน้า
- ภาพสำรองจาก HTML/CSS สำหรับ reduced motion และกรณีเริ่ม WebGL ไม่สำเร็จ
- ปุ่มดาวน์โหลดใช้ URL เดิมของแต่ละเกม ไม่สร้างเวอร์ชัน/build/checksum เพิ่ม
- ค้นหาไทย/อังกฤษ, รายการโปรด, กรอง source, sort และ query string พร้อม back/forward
- dialog ค้นหา/เมนู/สนับสนุน ใช้ native focus behavior และ Escape
- ลิงก์เก่า `?mod=<id>` และ anchor สำคัญมี mapping
- WebP จากภาพต้นฉบับ เก็บ QR สนับสนุนแบบ byte-for-byte

## ขอบเขตพรีวิว

- ไฟล์เว็บเดิมและ workflow production ยังอยู่ตามเดิม การ build V2 ใช้ `src/` และ `public/` แล้วสร้าง `dist/`
- ก่อนเปลี่ยน production ต้องเปลี่ยน workflow GitHub Pages ให้ build Astro และกำหนด `SITE_URL`/`SITE_BASE` ให้ตรงกับปลายทาง
- ข้อมูลม็อดเป็นข้อมูลที่มีอยู่ในโปรเจกต์ งานรอบนี้ไม่ได้ยืนยันเนื้อหาหรือลิงก์ดาวน์โหลดใหม่กับเจ้าของม็อด
- ยังไม่ได้วัด FPS บนอุปกรณ์มือถือจริงหรือ Core Web Vitals จากผู้เข้าชมจริง ฉาก 3D เป็น prototype ที่ต้องประเมินตามเครื่องเป้าหมาย
- gallery/trailer, release history แบบหลายเวอร์ชัน และ CMS เป็นงานระยะถัดไป ข้อมูลต้นทางยังถูกเก็บครบ
- สำหรับ QA responsive ในเบราว์เซอร์ที่ปรับ viewport ไม่ได้ ใช้ `node scripts/qa-viewport.mjs` แล้วเปิด URL ที่สคริปต์แสดง เป็น iframe viewport จำลอง ไม่ใช่การทดสอบฮาร์ดแวร์มือถือ

## ทิศทางหลักตามคำแนะนำเจ้าของ

เน้น PC ที่ความกว้าง 1440–1920px: หัวเรื่องและฉากอยู่ร่วมกันใน viewport แรก ภาพผลงานใช้พื้นที่กว้าง แผงดาวน์โหลดวางสองคอลัมน์และตามการเลื่อน ส่วนมือถือคง responsive พื้นฐาน

## หน้าคลังม็อดสำหรับ PC

- ตัวกรองด้านซ้ายคงตำแหน่งขณะเลื่อน แบ่งแนวเกมจาก tags เดิมของแต่ละเกม บางเกมอยู่ได้หลายแนว
- กริด 3 คอลัมน์บน PC ทั่วไป และ 4 คอลัมน์ตั้งแต่ 1700px ขึ้นไป พร้อมมุมมองรายการ
- ค้นหาชื่อไทย/อังกฤษ ผู้แปล และ tags; กรองแนวเกม แหล่งดาวน์โหลด และรายการโปรดร่วมกัน
- จำนวนในตัวกรองปรับตามคำค้น แหล่งดาวน์โหลด และรายการโปรด
- แบ่งหน้า 12 เกมต่อหน้า มีกรณีไม่พบผลลัพธ์และปุ่มล้างตัวกรอง
- `q`, `genre`, `source`, `sort`, `saved`, `view`, `page` อยู่ใน query string เพื่อ refresh แชร์ลิงก์ และใช้ back/forward ได้
- CSS ใช้สีและรูปทรงจาก design tokens กลาง เพื่อให้เปลี่ยนตามธีมของหน้าแรก
- เปิดพรีวิว PC: `http://127.0.0.1:4321/__qa/?width=1440&height=1000&page=catalog`
