## สิ่งที่เปลี่ยน

- นำฉาก 3D ที่เลือกมาเป็นหน้าแรก: G โลหะ (Game) แสงฟ้า/ม่วง/ทอง อนุภาคหลายระยะ และกล้องเคลื่อนตามการเลื่อนสามช่วง ตัวอักษรปรับจาก ก เป็น G ตามคำแนะนำล่าสุด รวมภาพสำรอง
- ส่วนผลงาน ผู้แปล อัปเดต คู่มือ และสนับสนุนใช้ธีมเดียวกัน
- คลังมีบรรยากาศแสงแบบเดียวกับฉากเปิด แถบค้นหาและตัวกรองพื้นกระจก ปุ่มและการ์ดสีฟ้า/ม่วง
- เพิ่มชั้น motion สำหรับ PC/Mac: เผยการ์ดและเนื้อหาเป็นจังหวะเมื่อเลื่อน แสงตามเมาส์ การ์ดเอียงแบบ perspective และภาพซ้อนระยะเล็กน้อย พร้อมวงโคจรและอนุภาคที่ตอบสนองการเลื่อน
- หน้ารายละเอียดใช้ภาพเกมขนาดใหญ่ หัวข้อและเมนูอ่านง่าย พร้อมแผงดาวน์โหลดสีเดียวกัน ปุ่มด้านบนเลื่อนไปเห็นช่องทางรับไฟล์
- ภาพปกรายเกมมี parallax; เมนูหัวข้อแสดงตำแหน่งอ่านและมีแถบ progress ด้านบน แผงรับไฟล์และขั้นตอนติดตั้งตอบสนอง hover
- ชั้น motion อยู่ใน `PageMotion.astro`, `page-motion.ts`, `page-motion.css`; ใช้ canvas 2D และ native scroll ไม่เพิ่ม Three.js ให้หน้าคลังหรือรายเกม เคารพ reduced motion และหยุดวาดอนุภาคเมื่อซ่อนแท็บ
- ใช้ธีมร่วมจาก `src/styles/universe.css` และฉากจาก `WorldJourney.astro` / `journey-scene.ts` / `world-journey.ts`
- Three.js โหลดเฉพาะหน้าแรก หยุดฉากเมื่อพ้นจอหรือซ่อนแท็บ มีปุ่มพัก ข้ามฉาก และภาพสำรอง
- คงข้อมูลและปลายทางม็อด 32 เกม รายการโปรด และระบบค้นหาเดิม
- เก็บดีไซน์ก่อนเปลี่ยนหน้าแรกใน `artifacts/design-archive/before-journey-home/`

## การตรวจ

- Astro check: 0 errors / 0 warnings / 0 hints
- Build: 36 หน้า รวม 32 รายเกมและ redirect จากพรีวิวเดิม
- `validate-migration.mjs`: ข้อมูล 32 เกมและ URL ตรงกับต้นฉบับ
- `verify-journey-motion.mjs`: สมการกล้องผ่านการตรวจการหยุด กลับทิศ และช่วงเวลา 30/60/120 Hz (ไม่ใช่การวัด FPS บนฮาร์ดแวร์)
- Browser: ค้นไทย/อังกฤษ ตัวกรองแนวและแหล่งดาวน์โหลด กรณีไม่มีผลลัพธ์ ล้างตัวกรอง เปลี่ยนหน้า และมุมมองรายการ
- ตรวจหน้ารายละเอียดและลิงก์รับไฟล์ต้นทาง รวมตำแหน่ง anchor ให้ปุ่มดาวน์โหลดอยู่ในจอ
- ภาพพรีวิวอยู่ใน `artifacts/qa/universe-home.png`, `universe-catalog.png`, `universe-detail.png` และ `universe-download.png`
- รอบ motion ตรวจบน viewport 1600px: การ์ดเอียงและแสง hover จริง, ค้นไทยและกรองแล้วการ์ดใหม่แสดงครบ, parallax ภาพปกและเมนูวิธีติดตั้งเปลี่ยนสถานะตาม scroll ภาพล่าสุดชื่อ `motion-catalog-hover.png` และ `motion-detail-hover.png`
