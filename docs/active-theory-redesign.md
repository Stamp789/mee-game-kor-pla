# The Language Portal — แผนออกแบบและรื้อระบบ

23 ตุลาคม 2026 · พรีวิวในเครื่อง · อ้างอิง https://activetheory.net/

ฉากแสงและกล้องที่เลือกใช้เป็นหน้าแรกจริงของพรีวิวแล้วที่ http://127.0.0.1:4321/ พร้อมคลังและหน้ารายละเอียดทั้ง 32 เกมในธีมเดียวกัน อ่านสถานะล่าสุดที่ [world-journey-site.md](world-journey-site.md) และรายละเอียดฉากที่ [journey-light-motion.md](journey-light-motion.md) เส้นทาง `/preview/journey/` เปลี่ยนไปหน้าแรก

## พรีวิวล่าสุด: Full-screen World Journey

ตามคำแนะนำให้ใกล้ Active Theory มากขึ้น เปลี่ยนหน้าเปิดเป็นฉาก 3D เต็มจอ โดยใช้ WorldJourney แทน hero แบบข้อความใหญ่กับประตูภาพเกม ฉากมีสัญลักษณ์ ก แบบ extrusion โลหะ ริบบิ้น อนุภาคเรืองแสง และวัตถุลอย ใช้แสงสะท้อนและ bloom

การเลื่อน native scroll ควบคุมกล้องตลอด 3 ช่วงใน sticky viewport: สัญลักษณ์และสวนแสง → หมุนกล้องเข้าใกล้ → เคลื่อนผ่านไปพบภาพเกมในพื้นที่สามมิติ พร้อมเปลี่ยนข้อความ chapter เมนูตรึงอยู่ด้านบน มีปุ่มข้ามไปผลงานและปุ่มพัก ambient motion

ไฟล์หลัก: `WorldJourney.astro`, `world-journey.ts`, `journey-scene.ts`, `journey.css` ฉากหยุด render เมื่อพ้นจอ/ซ่อนแท็บ ใช้ภาพสำรองเมื่อ WebGL ไม่พร้อม และ reduced motion ย่อเป็นช่วงเปิดภาพนิ่ง พรีวิวรุ่นแรกด้านล่างเก็บไว้เป็นแนวทางเดิมก่อนปรับรอบนี้

## ทิศทางที่เลือก

เปลี่ยนจากเว็บแสดงบล็อกข้อมูลเป็นประสบการณ์เดินทางเข้าโลกเกม: หน้าเปิดเต็มจอสีดำอมเขียว ประตูโลหะ แสงมิ้นต์และทอง อนุภาค และภาพจากเกมจริง ข้อความภาษาไทยเป็นจุดนำสายตา เมนูสั้น ภาพผลงานขนาดใหญ่ และพื้นที่ว่างที่มีจังหวะ

นำหลักการฉากมีมิติ การตอบสนองผู้ชม และ navigation เรียบของ Active Theory มาพัฒนาเป็นงานต้นฉบับของมีเกมก็แปล ไม่ใช้ source, model หรือ asset ของเว็บอ้างอิง

## เส้นทางหลัก

1. หน้าแรก: ประตูโลกเกม → เลือกเกมเด่น → ผลงานแปล → แนวคิดผู้แปล → อัปเดต → ขั้นตอนติดตั้ง → สนับสนุน
2. คลัง: ค้นหาไทย/อังกฤษ → กรองแนวเกม/แหล่งดาวน์โหลด → ดูกริดหรือรายการ → บันทึกเกม → รายละเอียด
3. รายเกม: ภาพและรุ่นม็อด → เงื่อนไขรุ่นเกม → วิธีติดตั้ง → ดาวน์โหลดต้นทาง → อัปเดตและแหล่งซื้อ

## ฐานระบบ

- Astro static output; URL ถาวร `/mods/<id>/` และ content collection แยกรายเกม
- ใช้ข้อมูลเดิม 32 เกม ไม่เปลี่ยนปลายทางดาวน์โหลดหรือสร้างเวอร์ชันที่ไม่มีข้อมูล
- Three.js โหลดแยกเฉพาะหน้าแรก: journey-scene.ts ดูแลฉากและ resource; world-journey.ts ดูแลปุ่มและวงจรหน้าเว็บ
- หยุด render เมื่อออกนอกจอ ซ่อนแท็บ หรือกดพัก เคารพ reduced motion และมีภาพ HTML/CSS สำรอง
- ค้นหาและรายละเอียดไม่ต้องรอฉาก 3D; รายการโปรดใช้ localStorage เดิม
- ธีมร่วมหน้าแรก คลัง และรายละเอียดอยู่ใน universe.css โดย journey.css ดูแลฉากเปิด

## ทำแล้วในพรีวิว

- หน้าแรกใหม่ทั้งหน้า ฉากประตูสามมิติ ภาพในเกม 3 โลก ปุ่มเปลี่ยนเกมและลิงก์ที่เปลี่ยนตาม
- โชว์เคส 4 เกม ภาพต่างขนาด ข้อความแนวคิดผู้แปล อัปเดต คู่มือ และสนับสนุน
- ธีมมืดเชื่อมหน้าแรก คลัง รายเกม และ dialog
- คงการค้นหา ตัวกรอง รายการโปรด ช่องทางสนับสนุน และข้อมูลม็อดจริง
- รองรับ responsive และภาพสำรองเมื่อ WebGL ใช้งานไม่ได้

## ระยะถัดไปก่อนใช้จริง

| ระยะ | งาน | เกณฑ์ส่งมอบ |
| --- | --- | --- |
| 1. ยืนยันภาพรวม | ทดลองพรีวิว ปรับสี ความเข้มฉาก และขนาดตัวหนังสือ | ยืนยันหน้าแรก คลัง และรายละเอียดตัวอย่าง |
| 2. แยกระบบให้จบ | รวม token ธีมกลาง แยก CSS ตาม page ลบฉากเก่าที่เลิกใช้หลังยืนยัน | ไม่มี CSS ธีมเดิมซ้อนหรือ dependency ที่ไม่ใช้ |
| 3. ปรับฉาก | วัด FPS บนเครื่องเป้าหมาย ปรับคุณภาพอนุภาค ตรวจหน่วยความจำเมื่อเข้าออก | ฉากไม่กระทบการค้นหาหรือดาวน์โหลด |
| 4. เนื้อหา | ตรวจ release/compatibility กับต้นทาง จัด screenshot และ gallery | ไม่อ้าง build หรือ checksum ที่ยังไม่ยืนยัน |
| 5. เปิดใช้ | ตรวจ SEO/sitemap, URL เดิม, base path, keyboard, contrast และปรับ GitHub Pages workflow | ผ่านค้นหา→รายละเอียด→ดาวน์โหลด และย้อนรุ่นได้ |

CMS เพิ่มภายหลังได้หากต้องการให้แก้ข้อมูลผ่านหน้าแอดมิน ไม่จำเป็นต่อพรีวิวนี้ ขอบเขตปัจจุบันไม่รวมสมาชิกหรือระบบเก็บไฟล์ม็อดเอง
