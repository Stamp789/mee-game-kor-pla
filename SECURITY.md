# Security policy

## Protected information

Do not commit passwords, access tokens, API secrets, private keys, PromptPay
account data beyond the intentionally published support image, or private user
information to this repository.

GitHub Secret Scanning and Push Protection are enabled for this public
repository. Local secret-like files are also excluded by `.gitignore`.

## Reporting a problem

Please report security concerns privately to the project owner through the
[มีเกมก็แปล Facebook profile](https://www.facebook.com/profile.php?id=61593924362608).
Do not publish sensitive details in a public issue.
